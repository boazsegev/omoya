# UX Practices

## Method
- Start from the primary user tasks; measure completion, time, errors and abandonment.
- Remove steps before polishing visuals.
- Validate with real users or analytics; label untested conclusions as heuristic.

## Flows
- Follow platform and web conventions unless a measured gain justifies deviation.
- Minimize steps, choices and recall; disclose complexity progressively.
- Prefill, remember and default safely.
- Prefer undo to confirmation.
- Design every state: empty, loading, error, success and offline.
- Give feedback within 100 ms, and progress for longer waits.

## Forms
- Ask only what the task needs.
- Validate inline, explain errors beside the field, and never discard input.
- Name buttons by outcome.

## Pages
- Order content by attention: value and primary action first, proof near the decision, reference last.
- Use one idea per section and one primary action per page.

## Audits
- Report location, problem, affected task, severity, evidence and specific fix, ordered by impact.
