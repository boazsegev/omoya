# Changelog

All notable changes to Omoya are documented here. This project adheres to [Semantic Versioning](https://semver.org/).

## 0.1.2 — Unreleased

- Web app: composer logging state now refreshes with agent/session updates, keeping the `Logging`/`No-log` chip accurate as sessions start, pause, or resume.
- TUI: pressing Esc closes the active block viewer or viewer filter before interrupting a running turn; a second Esc interrupts as before.
- OpenAI Responses endpoints (`openai` provider, including the ChatGPT Codex subscription): `web-search` takes the provider path through the hosted `web_search` tool (`tool_choice: "required"`). Availability is probed, not assumed: a result counts only with a `web_search_call` item; endpoints/models that reject or ignore the tool are remembered for the process and fall through to MCP/package. `web-fetch` always uses the package backend (OpenAI has no fetch tool; `open_page` timed out in practice). `Env.openaiWebSearch` is replaced by `Env.openaiWebCapabilities`.
- `claude` provider: `web-search` and `web-fetch` now take the provider path — Anthropic server tools (`web_search_20250305`, `web_fetch_20250910`) sent with the subscription OAuth headers and Claude Code identity — instead of always falling back to MCP/SearXNG/local fetch. Failures still fall through; `web.provider: false` opts out.
- Web app and TUI: the global agent state badge shows `working` whenever any agent works; `disconnected` shows only when none works, so a stale disconnect on another agent no longer masks live work. One shared rule (`aggregateState` in `lib/app/shared/format.js`) drives both.
- TUI status line: the plan shows once, in full, beside the context readout — `plan (Max): 5h 12/100 (12.0%) · resets in 2h · 7d …` — replacing the percent-only summary plus the separate plan line; the readout stays on one line (clips at the edge; hints give way first).
- Claude Pro/Max OAuth now has its own `claude` provider and login preset instead of `anthropic-claude`. Subscription requests supply Claude Code identity and headers and reversible `mcp__omoya__` tool names; Anthropic API-key requests remain unchanged. Existing `anthropic-claude` logins must sign in again under `claude` (no automatic credential migration). **Note**: Claude Pro/Max OAuth is designed to use the extra credits, not the subscription tokens, be aware.

- Web app: the context viewer becomes a TUI-style block viewer — one block per page titled `TOOL CALL [5/8] — read · 3.3`, with ‹ › « » navigation and the TUI’s keys (←/→ blocks, Alt+←/→ ten messages, ↑/↓ Space/B scroll, F search, C copy, Esc close). Ctrl+O toggles it like ^O (⇧⌘O/Ctrl+Shift+O still opens it). Filters, RegExp search, inline edit, rollback, and delete are kept; the page and edit state survive filtering and context refreshes. Context snapshots carry the tool `name` on tool blocks.
- TUI: a notification footer under the status line carries the turn clock — `working 12s` while a turn runs (no line when idle). It measures from the turn start to the Agent's latest event (stream delta, tool event or output), so it moves only when the agent does: a stalled network request or hung tool freezes it. GTUI gains a generic `view.footer(props, items)` element for app-pushed notification items.
- TUI: minimal syntax highlighting in language-tagged code fences — keywords, strings, numbers, and comments, one line-local tokenizer for every language, mapped onto existing theme roles (`accent`, `md.em`, `md.strong`, `muted`) so every theme applies without new keys. Output/prose/diff fences stay plain; copies stay byte-exact.
- TUI transcript: each user message opens its exchange with a blank line.
- TUI composer: a muted placeholder (`Ask anything · / for commands`, or `Queue a message for the agent…` while it works) and a chip line above the input for each `{{@path}}` attachment (`📎 name · 12 KB`, or `missing`). GTUI inputs gain a generic `placeholder` prop.
- TUI: a fresh session opens with a three-line welcome (name, model, thinking level, tool count; session; where to start) instead of the environment dump, and system messages show as one transcript line (`⚙ system · <first line> · 104 lines`) — full text in the ^O block viewer. The TUI transcript no longer uses the theme’s `message.system.preview` rows (the web app still does).
- TUI status line: while the viewed agent works, the hints switch to `Esc interrupt · ⏎ queue · ^O block viewer`.
- TUI status line: a context gauge (`▰▰▰▱▱▱▱▱ 34.0% · 68K/200K`, the fill turning to the error color from 80%) replaces `context: …`; the agent state shows as a theme-colored `● idle`/`● working`/`● disconnected` instead of emoji.
- TUI Markdown: headings take the accent color; fenced code sits in a light frame (`╭─ js`, `│ ` gutter, `╰─` — frame glyphs never enter copied text); task lists show ☐/☑ (copying back as `- [ ]`/`- [x]`); tables start at the text margin with a rule under the header row. GTUI tables gain generic `align: "start"` and `headerRule: <role>` options (default stays centered, no rule).
- TUI: reasoning blocks are labelled — `Thinking…` while they stream, then `Thought for 4.2s` (or `Thought` when the timing was not observed, e.g. a resumed session).
- TUI: each tool call is one transcript card — `✓ read  README.md · 4ms` (state glyph ✓/✕/◌/…/–, tool name, the argument that names its subject, run time), then the windowed output (or the arguments while the model writes the call) — replacing the separate `[tool call]`/`[tool ok]` headers and raw JSON arguments. A call still awaiting its result stays live only while its turn runs, so an interrupted call never holds back inline scrollback. The ^O block viewer still shows every raw block.
- **Breaking:** presentation layers move under one `App` façade (`lib/app.js`): `App.TUI`, `App.Web`, `App.GTUI`, and `App.Markdown` (folders `lib/app/{tui,web,gtui,markdown}`). `lib/tui.js`, `lib/web.js`, and `lib/markdown.js` are gone; `omoya/app` now exports `{ ...core, CLI, App }` (no top-level `TUI`, `GTUI`, `Web`, or `Markdown`).
- Web app: `/<prompt>` (and `//<name>`) now loads the expanded prompt into the composer for review/editing instead of submitting it (TUI parity); new server packet `command.fill {text}`.
- Sessions now persist the agent's configuration in the session file's metadata line (`agent` record — safe mode, thinking level, endpoint/model, display name/description, delegation permission, saving toggle): resuming a session (`--resume`, `/session-resume`, the web sidebar) restores the settings with the context, while an explicit launch-time `--model` still wins. `SessionStore` gains a `settings` accessor; `Agent` records changes as they happen (setSafe/setThinking/setModel/name/description/setSpawnPermission/sessionSaveSet).
- Session listings (web sidebar, palette, TUI resume menu) preview the first MEANINGFUL line of the first message — courtesy sentences ("Please …", "Hi!") and intro lines ending in ":" are skipped, list/heading/quote markers stripped (a bulleted request previews as its first item), code fences skipped — and carry the stored agent name when it isn't a default `agent-N` (web: row tooltip; TUI: before the preview). The web sidebar gains per-session rename/delete buttons (`session.rename {id}`, `session.delete {id}`; `SessionStore.renameById`/`deleteById`); a session held by a running agent can't be deleted.
- Fixed sessions listing twice (with differing message counts): a session first flushed before it had a nameable message kept its unnamed file when the derived name moved it; the old file is now removed with the move, and listings keep one entry per id (newest file).
- Merged messages (queued user messages, continued assistant turns, adjacent text/thinking blocks) now join with a blank line (`\n\n`) between sections instead of a single newline; routed worker replies end their `[Message from worker: …]` header with a newline.
- Web app: switching sessions (new, resume, add) keeps the current agent's model when the session stored none — a session's own stored model wins, and the launch-time `last-model.json` choice is only the first agent's default. Session listing/rename/delete now use the Env's own sessions folder (`sessionDir(env)`), matching where its agents save.
- bash tool: `ls` is no longer refused, so listings can pipe into other commands (`cd` and `ln` stay refused; the path scanner still applies).
- Anthropic provider: Claude Pro/Max (OAuth) requests now present the Claude Code client identity (`user-agent: claude-cli/<version> (external, cli)` + `x-app: cli`) alongside the identity system prompt — without the headers the subscription attestation rejected every request with a bare `429 rate_limit_error` whose message was just "Error". The presented version is resolved once per process: `ANTHROPIC_CLI_VERSION`, then the installed CLI's own `claude --version`, then a pinned fallback.
- Sanitize untrusted tool output at renderer ingest (`lib/app/markdown/text-safe.js`): ANSI escape sequences, C0/C1/DEL controls stripped and CR/CRLF normalized per streaming call (sequences split across chunks caught by a look-back buffer), so bash output can't corrupt TUI geometry, write to the real terminal, or litter the web DOM; SGR bold/italic/underline become balanced Markdown markers. Persisted results and `TOOL_DATA` events stay byte-exact.
- Web app: TUI feature parity and a redesigned interface — command palette (Ctrl/⌘+K), shared TUI themes with live previews (persisted to `tui.theme`), endpoint sign-in/out including browser OAuth and redirect paste, one live card per tool call (arguments, output, duration, error state), streaming thinking, agent and session renaming, delegation permission, new-session variants (read-only, unlogged), add-agent with a model, session clear/delete-all, inline context editing, argument autocomplete with hints, and every TUI slash command (unique prefixes resolve).
- Web app: collapsed thinking/tool/system cards preview the theme's `<role>.preview.maxRows` like the TUI (first line, omission marker, live tail while streaming; tool output stays windowed while it streams); Safari/WebKit dialogs (settings, themes, context, sign-in, palette) no longer collapse to their title; rendering keeps flowing when the browser withholds animation frames (hidden tab, occluded window).
- TUI: OAuth login presets in the login menu now run the browser sign-in instead of only inserting the `/endpoint-login` command; fixed `om --list` hanging on provider timeouts (the listing now shares the bounded model refresh and falls back to cached catalogues).
- Endpoints: dynamic (environment-detected) endpoints persist nothing and never survive their environment — detection re-probes behind a shadow map (rotated keys land immediately, removed keys drop the endpoint and clean up stale auth files), in-memory auth merges only, and `lastModel()` excludes secret/dynamic endpoints.
- read tool: `.ignore`/system files are now a relevance signal instead of an access wall — hidden from listings and searches but still readable by name; folder grep gains a size ceiling (`read.grepFileSizeLimit`, default 5 MB) and `binary: true` supports raw-byte greps; plain listings no longer skip unopenable files.
- Kimi provider: extracted attachment text is cached per IO (keyed by endpoint and file hash) instead of re-uploading every attachment on every request — each tool round used to cost two round trips per file.
- Website: restyled with a rewritten home page (serif/mono system fonts, light and warm-dark palettes, annotated command terminal, Safari and narrow-screen fixes) and a generated styled 404 page (root-relative, noindex, excluded from sitemap/search/link checks).
- Web app fixes: the page failed to load `/text-safe.js` (wrong asset path); a run that threw left the agent shown as working; a pending question was lost on reload or agent switch; a stray backdrop click refused a question; Markdown table alignment was blocked by the CSP.
- Other fixes: write/edit content mentioning device files (`/dev/null` and friends) was refused by the traversal scan; read ENOENT errors leaked absolute container paths; the TUI OAuth test spawned a real browser; a question's 5-minute tool-timeout window could extend a call past `toolTimeoutLimit`; dropped the unused `web.toolLines` setting (collapsed previews follow the TUI theme).
